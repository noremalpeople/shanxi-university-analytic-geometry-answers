## ✨ 项目特色

- **逐题讲解：** 按题意、所用知识、解题思路、推导证明、核查结论和易错提醒组织资料。
- **答案交叉核对：** 参考书后答案与提示；对于缺少过程的题目，补充必要的推导，并对疑点保留核查依据。

- **持续修订：** 欢迎反馈可复现的数学错误、题目差异和更清晰的解题方法。

## 📚 推荐学习方法

1. **先独立完成题目：** 先写出已知条件、所求目标和基本思路，尽量不要直接查看答案。
2. **分步骤核对：** 检查定义、定理和公式的使用条件，以及向量、坐标和代数变形是否正确。
3. **理解几何意义：** 不只记住最终方程，还要明确它表示的点、直线、平面或曲面。
4. **记录错误原因：** 将错误归类为概念不清、方法选择不当、计算失误或审题遗漏。
5. **回到教材复习：** 遇到不会做或答案差异较大的题目，应结合教材和课堂笔记重新推导。
6. **整理典型方法：** 将共线共面判断、距离与夹角计算、曲面分类、坐标变换等方法整理成个人笔记。

## 🔎 答案核查说明

答案资料用于辅助学习和核对，不应替代独立思考。对于以下情况，建议进行二次检查：

- 教材版次不同，导致题目条件或编号发生变化；
- 书后答案只给出结论，缺少中间推导；
- 向量方向、坐标系约定或正负号可能影响结果；
- 含参数题目在特殊参数取值下出现退化情形；
- 几何方程形式正确，但定义域或实际图形范围未说明。

如果发现疑似错误，请尽量提供章节、题号、教材版次、问题所在步骤以及可复现的推导或反例。
