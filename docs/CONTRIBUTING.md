# 参与修订

每个习题的编号都对应书中 `章.节-题号`。提交问题或修订时请附：教材版次或图片页码、原题条件、现有讲义公式、可复现的反例或推导过程。避免仅用一句“答案不对”而没有数学证据。

修改第三章请编辑 `chapters/03/chapters/03-01.tex` 至 `03-05.tex`，必要时在 `tests/verify_ch03.py` 增加 SymPy 回归检查，随后运行 `bash build.sh` 重建三份 PDF，至少抽查受影响的 PDF 页。每次修订需要更新 `CHANGELOG.md`；如涉及书后差异，还要同步 `docs/AUDIT.md`。

公开仓库不要提交版权不明的教材扫描件或原书整页复制品；只上传本项目原创文字、公式、数学示意图和测试脚本。
